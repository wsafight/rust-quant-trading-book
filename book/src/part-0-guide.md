# 第零部分导读：先学会运行、观察与复现

这一部分面向尚不熟悉终端、编程、测试或 Git 的读者。如果你已经能独立创建小项目、运行测试、阅读错误并使用 Git 保存修改，可以直接尝试[阶段检查点零](gate-0-foundation.md)；通过后不必逐章学习本部分。

本部分不会提前讲异步、交易所接口或复杂策略。目标是建立后续全书依赖的最小工作方式：知道输入在哪里、程序做了什么、失败发生在哪一层，以及怎样让别人复现你的结果。

## 四章怎样连接

| 章节 | 核心问题 | 产物 |
| --- | --- | --- |
| 第 0.1 章 | 程序在哪里运行，命令结果怎么看 | 一份可重复执行的环境记录 |
| 第 0.2 章 | 程序怎样接收输入并产生输出 | 一张交易流水汇总表 |
| 第 0.3 章 | 文本、JSON、时间和数值为何容易出错 | 一份小型行情数据质量报告 |
| 第 0.4 章 | 修改怎样被记录、比较和恢复 | 一个有清晰提交历史的学习项目 |

## 带着同一个小任务学习

四章共用一组简化成交记录：

```text
timestamp,side,price,qty
2026-01-02T09:00:00Z,buy,100.00,2
2026-01-02T09:00:01Z,sell,101.00,1
```

你会先找到并查看文件，再把一行输入拆成字段，检查时间、方向、价格与数量，最后计算买卖数量和现金变化。此处不追求真实交易账务，只训练“输入、规则、输出、错误和证据”这五件事。

## 本部分的学习方式

每完成一个动作，都保留四项信息：

1. 运行了什么命令；
2. 使用了什么输入；
3. 得到了什么输出；
4. 失败时改了什么。

不要把红色错误信息立即关闭。错误是程序给出的观察结果：先找到第一条自己能理解的信息，再判断是命令不存在、路径错误、输入错误、编译失败，还是程序成功运行但业务结果错误。

## 第一次、第二次与卡住时

- **第一次：** 顺序完成四章，每次只做一个命令或一个数据变化。
- **第二次：** 不看正文重做预备项目，并把所有口头步骤写进 README。
- **卡住时：** 回到第 0.1 章的失败分类；不要在当前目录和输入尚不明确时继续尝试新工具。

## 进入第 1 章前

通过 Gate 0 时，你应能在一个陌生但说明清楚的小项目中：

- 找到输入和程序入口；
- 运行程序与测试；
- 修改一个输入并预测结果；
- 根据第一条错误定位到文件和行；
- 使用 Git 展示自己的修改；
- 把运行命令、输出与已知限制写进 README。

这些能力看似基础，却决定了后面能否独立完成几十次“运行、改坏、修复和留证据”的学习循环。
