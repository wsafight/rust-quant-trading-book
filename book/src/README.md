# Rust 从入门到量化交易工程师

## 用 Rust 构建正确、可回放、可恢复的交易系统

量化交易工程不是“用 Rust 写一个能下单的脚本”。真正的工作是把不完整、延迟且可能乱序的市场信息，变成受风险约束的订单；再把交易所返回的部分事实，恢复成可以审计的订单、仓位、现金和 PnL。

本书沿一条真实的数据链展开：

```text
交易所行情 -> 本地订单簿 -> 公允价/信号 -> 报价与对冲意图
     ^                                      |
     |                                      v
对账与恢复 <- 仓位/余额/成交 <- 订单状态机 <- 独立硬风控
                         |
                         v
                  PnL、延迟与告警
```

你会先用 Rust 的所有权和类型系统表达事实，再学习订单簿、永续合约和做市，最后把它们连成可确定性回放、能在部分失败下恢复的系统。每章都围绕工程产物，而不是知识点背诵。

## 读完会得到什么

- 能写出不会混淆价格、数量、订单 ID 和币种的 Rust 领域模型。
- 能重建 L2 订单簿，并在增量缺口后停止发布错误行情。
- 能处理 fill-before-ack、cancel/fill race、重复成交和请求超时。
- 能解释做市收益、逆向选择、库存风险、资金费率和对冲成本。
- 能构建含费用、延迟和保守成交假设的事件驱动回测。
- 能用 benchmark、profile、指标、日志、对账和故障演练证明系统行为。

## 从浅入深的六个阶段

| 部分 | 章节 | 学习重点 | 阶段产物 |
| --- | --- | --- | --- |
| Rust 语言与工程基础 | 1-8 | 语法、所有权、领域建模、集合、错误、trait、Cargo | 可测试的领域类型与 Rust workspace |
| 实时系统基础 | 9-12 | 订单簿、并发、Tokio 网络、性能测量 | 有界事件管线与订单簿基线 |
| 市场、产品与执行 | 13-17 | 微观结构、订单执行、衍生品、量化数学、账本与对账 | 可手算并可编码验证的交易模型 |
| 构建交易系统 | 18-22 | 行情同步、adapter fixture、OMS、做市与硬风控 | 行情到订单/仓位的完整状态链 |
| 研究与生产 | 23-26 | 回测、仿真校准、统计验证、可靠性与事故响应 | 可复现研究和生产运行证据 |
| 项目与职业路径 | 27-28 | 贯穿项目、24 周路线、作品集与面试 | 可演示的完整工程项目 |

完全初学者按顺序阅读；已有 Rust 或后端经验的读者也建议先用每章练习验证基础，再跳到自己的缺口。后面的章节会反复使用前面建立的类型、时间、状态和测试约定。

## 怎样开始阅读

如果不确定从哪里开始，先阅读[全书阅读指南](reading-guide.md)。它提供 Rust 初学者、后端工程师、量化研究者和交易系统开发者的不同入口，也解释配套代码、阶段检查点和贯穿案例怎样配合。

顺序阅读时，每章建议完成四个动作：先明确要避免的交易错误，运行并改坏最小例子，完成一个输入或时序变体，最后保存测试、fixture 或报告作为证据。每一部分末尾的阶段检查点用于连接多章内容；未通过时按检查点中的回补表返回对应章节。

时间有限时，不要只读标题后跳到综合项目。先运行一章的练习或检查点：能独立解释不变量、注入故障并复现结果，就继续；只能复述概念，就从该章正文补齐。

本书不承诺交易盈利，也不把测试网当生产市场。目标是培养一名对状态、证据和资金风险负责的工程师。

开始阅读：[序言：先成为可信赖的工程师](preface.md)，然后进入[全书阅读指南](reading-guide.md)。第一次接触交易系统的读者，建议接着阅读[零基础预备课](beginner-primer.md)。
