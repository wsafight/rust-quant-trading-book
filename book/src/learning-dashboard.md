# 学习看板：我在哪里，下一步做什么

这页不是新的学习内容，而是全书的操作面板。第一次开始、完成一个章节、通过一个检查点或中断数周后回来时，都可以从这里重新定位。

确定起点后，如果想知道每章哪些内容第一次必须读、哪些适合第二遍或特定方向，请打开[阅读层级地图](reading-level-map.md)。

## 一次学习会话怎么安排

一次 60～90 分钟的学习可以只完成一个小循环：

1. **5 分钟定位**：看本章学习导航和第一次阅读建议，写下本次唯一目标。
2. **20 分钟理解**：阅读一个概念和对应交易场景，用自己的话写一句不变量。
3. **30 分钟操作**：运行示例，只改变一个输入、顺序或边界。
4. **20 分钟验证**：补一条测试或手算，对照预期与实际。
5. **10 分钟留证据**：记录命令、输入、结果、失败和当前限制。

时间不够时，可以停在一次可恢复的中间状态，但要写下下一步。不要为了“读完一章”跳过实际运行。

## 一章的退出条件

离开一章前至少回答：

- 本章新增了哪个事实、状态或边界？
- 我运行了什么，而不只是读了什么？
- 哪个正常输入通过？
- 哪个边界或错误输入被拒绝？
- 我主动改坏了什么，系统怎样暴露问题？
- 本章项目增量已经接到前一章了吗？
- 当前实现不能证明什么？

答不出其中三项以上时，先完成章末基础题和组合题，不急着进入下一章。

## 一个部分的退出条件

每个部分按照相同节奏收口：

```text
完成各章最小产物
-> 完成该部分带反馈实验
-> 挑战阶段检查点
-> 根据失败项回补
-> 接受一次独立评审
-> 冻结版本和证据索引
```

检查点没有通过时，不需要重读整个部分。使用回补表定位到具体章节，再用最小失败输入复验。

## 中断后怎样恢复

中断数天或数周后，不要从记忆猜进度。依次查看：

1. 最近一次通过的 gate 或冻结版本；
2. 最近一次运行命令和输入 checksum；
3. 尚未解决的失败测试；
4. 当前已知限制；
5. 下一项只有一个动作的任务。

建议在自己的仓库维护：

```markdown
# 当前学习状态

- 当前阶段：
- 最近通过的 gate：
- 当前可运行命令：
- 最近失败的最小反例：
- 正在验证的假设：
- 下一步唯一动作：
- 暂时不做：
```

## 什么时候暂停继续阅读

出现以下情况时，暂停新章节：

- 只能复述术语，无法预测输入变化后的结果；
- 示例能够运行，但说不清输入、单位或状态 owner；
- 修复错误主要依赖随机加 `clone`、重试或默认值；
- 当前阶段的关键故障无法稳定复现；
- 报告中的数字无法追到输入、配置和版本；
- 需要作者口头解释才能完成已经写明可复现的操作。

暂停不是落后，而是在防止后续复杂度掩盖当前缺口。

## 今天就开始

如果仍不知道选哪条路，只做下面一件事：

- 编程基础不稳：尝试 [Gate 0](gate-0-foundation.md)。
- 编程基础稳定：完成[第 1 章自评](01-roadmap-and-setup.md#17-起点自评)。
- 已有项目：用[最终项目评审](appendix-h-review-scripts.md#h8-最终项目评审)尝试一次无口头提示的复现。

让失败结果决定下一页，而不是让目录顺序替你决定。
