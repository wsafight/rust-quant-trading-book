# 阅读层级地图：哪些先学，哪些后学

本页集中标记第 0.1～28 章的阅读层级，避免在正文近千个小节标题上重复添加标签。读者先按本页确定范围，再使用每章开头的“第一次阅读建议”决定顺序。

## 四种层级

- **必学：** 所有目标读者都需要，是后续章节默认成立的契约。
- **方向必学：** 共同主线读到结论即可，选择相应毕业方向后需要完成实现与评审。
- **进阶：** 第一次可以跳过，完成本部分基础闭环后再读。
- **参考：** 遇到具体设计、排障、求职或维护任务时查阅。

每章的练习、回顾和“离开本章前”行动卡始终属于必学，不因正文小节标为进阶而跳过。
